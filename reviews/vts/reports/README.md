# VTS review reports

Store actual review records only. This folder starts without completed reviews.
Suggested name: `<study-id>__rev-<revision>__<reviewer-id>__YYYYMMDD.md`.
Record input hashes, source snapshots, scope, checked/unchecked counts, findings and verdict.
Keep author correction records separate from independent review reports.
Do not create an attestation without a real review event.
