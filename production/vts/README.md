# VTS publication outputs

Use only an approved research revision for release-ready artwork.
Prototype drafts must be labelled DRAFT and retain their limitations.
Store output by study ID, direction, route variant and revision.
The dataset and sources remain outside this folder.

Every graphic label and report instruction must resolve to an approved reporting event, geometry or claim.
The researcher must not invent safe tracks or reporting positions for the designer.
A PDF export is not navigational approval.
Final release requires marine review, graphic QA, source-currency checks, permissions and editorial authorisation.
