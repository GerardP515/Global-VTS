# Editorial Regions

The project currently uses 17 editorial regions.

These regions exist to organise research and publication structure. They do not represent an IMO geographical coding system.

| Code | Region |
|---|---|
| BIS | British Isles and southern North Sea |
| NOI | Norway and Iceland |
| BAL | Baltic Sea and approaches |
| NSC | North Sea continental coast |
| FIC | France, Iberia and Canary Islands |
| MED | Mediterranean and Black Seas |
| SAF | Southern Africa |
| RSA | Red Sea and Arabian region |
| IOS | Indian Ocean and South Asia |
| MSI | Malacca, Singapore and Indonesia |
| CSC | China Sea and China |
| NWP | North-west Pacific |
| AUS | Australia |
| NPC | North America Pacific coast |
| CAP | Central and South America Pacific coast |
| CGP | Caribbean, Gulf of Mexico and Panama |
| NAC | North America Atlantic coast |

## Rules

1. Region is metadata, not identity.
2. Canonical IDs do not contain the region.
3. A regional reference may be generated for human use.
4. If a scheme crosses regional boundaries, record the primary editorial region and any secondary region separately.
5. Region changes do not change the canonical entity ID.

## Legacy note

Earlier discussion used `SPC` as a possible code for the Central and South America Pacific coast.

The project schema uses `CAP` to avoid confusion with “South Pacific”.
